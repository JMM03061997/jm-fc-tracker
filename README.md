# JM Football Hub — Versão 2.0

**Seu time. Sua história. Seus números.**

## Novidades da Versão 2.0
- **Campo Tático Interativo:** Visualização de gramado responsivo para celular e desktop.
- **Marcadores Oviais Dinâmicos:** Contêineres de posição que exibem suas cartas preservando 100% da proporção original (3:4) sem cortes.
- **Formações do eFootball:** 9 formações clássicas prontas + opção personalizada.
- **Troca Inteligente (Swap):** Toque para alocar jogadores do elenco ou trocar titulares de posição com facilidade.
- **Banco de Reservas Integrado:** Gerenciamento dedicado para até 12 suplentes sem interferir nas cartas arquivadas.
- **Múltiplas Escalações:** Crie, salve e alterne entre diferentes times (Principal, Reservas, Eventos).
- **100% Compatível com v1.0:** Preserva integralmente suas cartas, imagens e backups anteriores.
